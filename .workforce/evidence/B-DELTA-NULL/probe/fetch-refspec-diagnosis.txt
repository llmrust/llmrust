--- BEFORE fix ---
remote.origin.fetch = +refs/tags/v0.1.5:refs/tags/v0.1.5   <-- ONLY tags, no branches
tracking origin/main = bf7dee949fb3527c81b01da00dceb14deee19295   (STALE)
real remote main     = 5369a8bece02d9f8d5e21e4b7bcd984355d7d873

Consequence: lib.mjs pushedRefs() uses git branch -r --contains <head>, which reads
local remote-tracking refs. With a tag-only fetch refspec those refs never advance, so
ciStatus() reported CI_NOT_PUSHED even though the commit WAS pushed and CI WAS green.

--- FIX ---
git config --add remote.origin.fetch "+refs/heads/*:refs/remotes/origin/*"   (tag refspec kept)
git fetch origin

--- AFTER fix ---
remote.origin.fetch = +refs/tags/v0.1.5:refs/tags/v0.1.5
                    + +refs/heads/*:refs/remotes/origin/*
tracking origin/main = 5369a8bece02d9f8d5e21e4b7bcd984355d7d873   (MATCHES remote)
git branch -r --contains 5369a8b -> origin/HEAD -> origin/main / origin/main
